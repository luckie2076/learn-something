# 单元 4 · 排版与颜色

## 学习目标

掌握字体、颜色、圆角、阴影等"视觉令牌"类工具，理解 Tailwind 的**设计令牌（design tokens）**组织方式。

## 你将看到

- `text-xl font-bold` 改变字号与字重
- `text-red-500` / `bg-blue-600` 等带档位的颜色
- `rounded-lg`、`shadow` 等形状与层次工具

## 核心原理（为什么 / 机制）

- **颜色 = 调色板 + 深浅档位**：`red-500` 表示在 `red` 调色板里取第 500 档。同一调色板有 `100–900` 等多档，统一语义（如 `500` 通常为主色、`100` 为最浅背景浅色）。这种命名让"换肤""深浅模式"只需换令牌值，不用改每个类名。
- **这些令牌来自默认主题**：Tailwind 内置一组设计良好的令牌；它们都可以通过 `@theme` 覆盖或扩展（见单元 7）。
- **形状与层次同样分档**：圆角 `rounded-sm/md/lg/xl`、阴影 `shadow` / `shadow-md` / `shadow-lg` 都是按"强度档位"命名，便于在全站保持一致的视觉语言。

## 关键代码思路

```tsx
<h1 className="text-xl font-bold text-slate-800">标题</h1>
<button className="bg-blue-600 text-white px-4 py-2 rounded-lg shadow">
  主按钮
</button>
```

## 如何运行校验

在本单元目录下 `pnpm install && pnpm dev`，文本字号/字重生效；按钮呈现蓝色背景、白色文字、大圆角与投影。尝试改成 `bg-red-500 rounded-sm` 观察令牌切换效果。

## 常见误区

- 凭感觉写 `text-[17px]` 这类任意值——优先用内置令牌以保持一致性，任意值只用于真正特殊的场景。
- 混淆档位语义：`50/100` 偏背景浅色，`500` 偏主色，`700/900` 偏文本/深色。
