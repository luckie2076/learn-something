# 第二章 · 表达式与属性

> 教学导向：每节先讲「为什么这样设计」，再展示最小可运行代码。
> 运行方式：在项目根目录执行 `pnpm install`，然后 `cd 02-expressions && pnpm dev`。

---

## 1. 大括号 {} 嵌入表达式

**是什么**：在 JSX 中，`{}` 是「动态窗口」——里面可以写任何 JavaScript 表达式。

**为什么**：JSX 是声明式的 UI 描述，`{}` 让你在静态结构中嵌入动态数据。变量、计算结果、函数调用，统统塞进去。

## 2. 属性动态绑定

**是什么**：标签属性值也可以用 `{}` 绑定，让 `src`、`title`、`placeholder` 等根据数据动态变化。

**为什么**：数据和 UI 分离的核心——你只描述「属性 = 这个变量」，React 负责在变量改变时更新 DOM。

## 3. style 对象语法

**是什么**：JSX 的 `style` 接收 JS 对象，而非 CSS 字符串。属性名用 camelCase，值用字符串或数字。

**为什么**：对象可以被 JS 动态计算（比如根据条件切换颜色），这是字符串做不到的。两层 `{{}}`：外层是 JSX 表达式，内层是对象字面量。

## 4. className 与特殊属性

**是什么**：JSX 中 `class` 写作 `className`，`for` 写作 `htmlFor`，这是因为 `class` 和 `for` 是 JavaScript 保留字。

**为什么**：JSX 本质是 JS，保留字不能直接用。React 做了映射让你写起来像 HTML，但底层严格遵守 JS 规则。
