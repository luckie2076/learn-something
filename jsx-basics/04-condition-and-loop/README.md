# 第四章 · 条件与循环渲染

> 教学导向：每节先讲「为什么这样设计」，再展示最小可运行代码。
> 运行方式：在项目根目录执行 `pnpm install`，然后 `cd 04-condition-and-loop && pnpm dev`。

---

## 1. 三元表达式 ? :

**是什么**：在 `{}` 里用 `条件 ? 渲染A : 渲染B` 实现二选一显示。

**为什么**：JSX 里不能写 `if/else` 语句（只能写表达式），三元恰好是表达式，完美适配 `{}` 语法槽。

## 2. && 短路渲染

**是什么**：`条件 && <JSX>` 只在条件为 true 时才渲染 JSX，否则什么都不渲染。

**为什么**：React 不渲染 `false`、`null`、`undefined`。利用 JS 短路逻辑，一行就能实现「有就显示，没有就隐藏」。注意：当条件可能是 `0` 时不要用 `&&`（React 会渲染出 `0`）。

## 3. map 列表与 key

**是什么**：`Array.map()` 把数据数组转换为一组 JSX 元素。`key` 是一个唯一的标识符，帮助 React 追踪每个元素。

**为什么用 map**：数据驱动 UI——你只管维护数据数组，React 自动渲染对应的 UI。

**key 为什么必须**：React 用 key 判断「这个元素还在吗」，从而高效复用 DOM。用数组下标作 key 在增删数据时会出错——因为元素位置变了，但 React 以为它还是原来那个。
