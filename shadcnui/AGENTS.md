# 目的
帮助用户来学习 shadcn/ui 的使用
# 环境
    * vite
    * react + typescript
    * pnpm
    * tailwindcss
    * git
    * shdcn/ui
# 要求
1. 请以教学为导向的。
    * 设计合适数量的教学单元，每个单元应该完全互相隔离（包括运行环境），互不影响。
    * 除了对应的教学内容外，应该避免引入过多复杂、非必要的内容。
    * 更多的解释为什么，以及其背后的实现机制，而不仅仅是怎么做。
2. 教学内容放在各自教学单元的 readme 中。
3. 代码极简，仅用于演示，避免引入非必要且复杂的内容。
4. 应该基于最新的库或包，基于最新的文档和使用教程。
5. 请使用中文回答。
