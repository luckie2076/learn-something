# 阶段 1：基础语法

本阶段的目标：掌握 Rust 的**变量、类型、函数、控制流**四大基础，能读懂并写出最普通的程序。

```bash
cd stage-1-syntax
cargo run
```

## 0. 与 C 的差异速查

Rust 与 C 同属"花括号 C 系"语言，语法高度同源。这里只列你（已有 C 基础）**最容易踩坑**的差异：

| Rust | 说明 | 与 C 的对比 |
|------|------|-----------|
| `let x = 5` | 变量**默认不可变** | C 的 `int x = 5` 天生可变；Rust 反过来了 |
| `let mut y = 5` | `mut` 显式声明可变 | 相当于 C 的普通变量 |
| `let x: i32 = 5` | 类型写在变量**后** | C 是 `int x = 5`（类型在前）；Rust 声明顺序反过来了 |
| `fn add(a: i32) -> i32` | 返回类型写在 `->` 后 | C 是 `int add(int a)`；参数也**必须**标注类型 |
| `if n > 5 { } else { }` | 条件**不加括号**，分支必须带花括号 | C 必须 `if (n > 5)`；Rust 括号可省 |
| `for i in 0..3` | 区间迭代 | C 没有；`for (i = 0; i < 3; i++)` 是"初始化+条件+步进"三段式 |
| `println!("{}", x)` | 格式化输出是**宏** | C 的 `printf("%d", x)`；Rust 用 `{}` 而非 `%d` |

## 1. 变量：默认不可变

```rust
let x = 5;      // 不可变：一旦绑定，不能重新赋值
// x = 6;       // 编译错误！cannot assign twice to immutable variable
let mut y = 5;  // 加 mut 才可变
y = 6;          // OK
const MAX: u32 = 100; // const：编译期常量，必须标注类型
```

**为什么默认不可变？** 这是 Rust 的安全理念：能不变就不变，减少"变量被意外修改"这类 bug。
C 里变量天生可变，全靠程序员自律；Rust 把这个约束交给编译器——`mut` 相当于"声明式地承认这里需要改变"，比 C 更严格，也更难写出意外改值的 bug。

## 2. 标量类型

| 类型 | 例子 | 说明 |
|------|------|------|
| `i32` / `i64` | `-42` | 有符号整数（默认 `i32`，对应 C 的 `int`） |
| `u32` / `u64` | `42` | 无符号整数（对应 C 的 `unsigned int`） |
| `f64` / `f32` | `3.14` | 浮点数（默认 `f64`，对应 C 的 `double`） |
| `bool` | `true` | 布尔（对应 C 的 `bool`，但更严格：不能当整数用） |
| `char` | `'中'` | **4 字节** Unicode 字符（C 的 `char` 只有 1 字节 ASCII） |

```rust
let a: i32 = -42;
let b: u64 = 42;
let c: f64 = 3.14;
let ok: bool = true;
let ch: char = '中';   // 注意用单引号；字符串用双引号
let inferred = 10;     // 类型可推断，不写也能编译（C 必须显式声明）
```

> 与 C 的整数/浮点几乎一一对应，但 Rust 有两点更严格：`bool` 不能隐式转成整数（C 里 `if (ptr)` 合法，Rust 不行）；有符号与无符号不会隐式转换（`u32` + `i32` 直接报错，C 会悄悄截断）。

## 3. 复合类型：元组与数组

```rust
let tup: (i32, f64, &str) = (500, 6.4, "元组"); // 元组：不同类型打包
let (t0, _t1, t2) = tup; // 解构，_ 表示忽略该位
let first = tup.0;       // 或按索引访问

let arr: [i32; 3] = [1, 2, 3]; // 数组：同类型、长度固定
let arr_first = arr[0];
```

- **数组**与 C 几乎一致：同类型、定长、可索引、在栈上。`[i32; 3]` 对应 C 的 `int arr[3]`（声明顺序不同）。
- **元组**是 C 没有的类型——C 只能用 `struct` 包不同类型（那正是阶段 3 的 `struct`）；如果你用过 Python 的 tuple / TS 的 tuple，就是这个概念。
- 可变长度的容器（C 里要 `malloc` + 手动 `realloc` 管理）是 `Vec`，在阶段 5 讲解——届时你会看到 Rust 把 C 程序员手写的动态数组封装成了类型。

## 4. 函数

```rust
fn add(a: i32, b: i32) -> i32 {
    a + b // 最后一个表达式就是返回值（不带分号）！
}
```

对照 C 的 `int add(int a, int b) { return a + b; }`，三个要点：

1. 参数**必须标注类型**（与 C 相同，这是编译期强类型语言的要求）。
2. 返回类型写在 `->` 后（C 写在函数名前）；无返回值时省略 `->`（返回 `()`，对应 C 的 `void`）。
3. **表达式 vs 语句**：Rust 中"不带分号"的是表达式（有值），"带分号"的是语句（无值）。所以 `a + b` 是返回值（相当于 C 的 `return a + b;`），`a + b;` 则变成语句、函数会隐式返回 `()`。C 里赋值是表达式（`x = y = 3` 合法），Rust 把这个"表达式即值"的思想贯彻到底——**整个函数体就是一个表达式**。

## 5. 控制流

```rust
// if / else：条件不加括号，分支必须带花括号（C 的 if 必须加括号，且单语句可省花括号——Rust 两者都不行）
if n % 2 == 0 {
    println!("偶数");
} else {
    println!("奇数");
}

// if 是表达式，可以赋值（C 里只能用三元运算符 ?: 达到同样效果）
let label = if n > 5 { "大" } else { "小" };

// loop：无限循环，break 可携带返回值（C 没有带值的 break）
let mut count = 0;
let result = loop {
    count += 1;
    if count == 3 {
        break count * 2; // 返回 6
    }
};

// while：条件循环，与 C 一致
while m > 0 {
    m -= 1;
}

// for：区间迭代（C 的 for 是"初始化+条件+步进"三段式，没有这种写法）
for i in 0..3 {
    println!("i = {i}");
}
```

`0..3` 是"前闭后开"区间（0, 1, 2，相当于 C 的 `for (i = 0; i < 3; i++)`），`0..=3` 是"闭区间"（0, 1, 2, 3）。

## 6. 字符串初识：`String` 与 `&str`

Rust 有两种字符串类型，这是新手最容易困惑的点：

```rust
let mut s = String::from("hello"); // String：可变、可增删，在堆上
s.push_str(", world");

let literal: &str = "字面量";       // &str：字符串切片/字面量，不可变、只读借用
```

对照 C 的字符串模型就很好理解了：

- **字符串字面量**（代码里直接写的 `"..."`）类型是 `&str`——它存在程序二进制里，只读，对应 C 的 `"hello"` 字面量（存储在只读段）。
- **`String`** 是运行时在堆上分配的、可变的字符串——对应 C 里 `malloc` 出来的缓冲区，但**自动管理释放**（不用你 `free`，这正是阶段 2 所有权要解决的）。C 里手动拼接要 `strcat` + 担心缓冲区溢出，Rust 里直接 `push_str`。
- 阶段 2 学完所有权和借用后，`&` 的含义就完全清楚了，先记住"`String` 可变、`&str` 只读"即可。

## 常见坑

- **忘了 `mut`**：`cannot assign twice to immutable variable` —— 按提示在 `let` 后加 `mut`。
- **函数体忘了写返回值**：最后一行带了分号，导致返回 `()`，类型不匹配报错。
- **字符用了双引号**：`'a'` 是 char（单引号），`"a"` 是字符串（双引号），别混。
- **`if` 分支类型不一致**：`if` 作为表达式赋值时，所有分支必须是同一类型（编译期强制）。
