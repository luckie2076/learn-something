# 03 · Attention —— 让 token 之间"交换信息"

> **角色**：LLM 能读懂语境的根本原因。让每个 token 看到句子里的其他 token，吸收上下文。

---

## 一句话理解

Attention 接收一个向量矩阵 `[seq_len, hidden_dim]`，输出一个**形状完全相同**的向量矩阵。
不同的是：每个 token 的向量已经吸收了它能看到的上下文信息。

---

## 核心概念

### 为什么要 Attention？

u02 的 embedding 是**无上下文**的——同一个 token 在任何句子里向量都相同：

```
"小猫" 中的 "猫" → embedding → [0.23, -0.57, ...]
"黑猫" 中的 "猫" → embedding → [0.23, -0.57, ...]  ← 完全相同！
```

但人类的语言里，"小猫"和"黑猫"中的"猫"含义并不完全相同。Attention 要做的事就是：
**让 "猫" 看到它前面的 "小" 或 "黑"，从而调整自己的向量**。

### Attention 之后的变化

```
进入 attention 前：           离开 attention 后：
"小猫" 的 "猫" [0.23, -0.57]  →  [0.31, -0.42, ...]  ← 不同了！
"黑猫" 的 "猫" [0.23, -0.57]  →  [0.15, -0.68, ...]  ← 不同了！
```

同一个 "猫" 吸收了各自的上文后，向量开始**分化**——这就是模型"理解语境"的本质。

---

## 形状不变 → 可堆叠

Attention 的关键特性：**输入和输出形状完全相同**。

```
输入:  [5, 896]
输出:  [5, 896]    ← 形状不变！
```

这意味着它可以像**积木一样堆叠**。典型的 Transformer 模型有几十层 attention，
每一层都接收上一层的输出，做一次上下文融合。u04 的模型里就堆了 **24 层**（Qwen3-0.6B）。

---

## Causal Mask（因果遮罩）—— "不偷看未来"

在生成文本时，模型不能看到后面的内容（因为后面的内容还没生成），
所以 attention 有一个 **causal mask**（因果遮罩）：

```
位置 0 "中" →  只能看到 [中]
位置 1 "国" →  只能看到 [中, 国]  
位置 2 "的" →  只能看到 [中, 国, 的]
位置 3 "首" →  只能看到 [中, 国, 的, 首]
位置 4 "都" →  只能看到 [中, 国, 的, 首, 都]
```

每往上走一层，信息传递范围不变，但信息融合得更深。

---

## Q、K、V 是什么？

Attention 内部有三块矩阵 `W_q`、`W_k`、`W_v`，都是 `[d, d]` 形状（d = hidden_dim）：

| 缩写 | 全称 | 作用 |
|------|------|------|
| Q (Query) | 查询 | "我在找什么？" —— 当前 token 的"搜索意图" |
| K (Key) | 键 | "我是什么？" —— 每个 token 的"身份标签" |
| V (Value) | 值 | "我有什么信息？" —— 每个 token 的"信息内容" |

**流程**：每个 token 用自己的 Q 去和其他 token 的 K 做匹配（计算相似度），
匹配度越高权重越大，然后用权重从 V 中提取信息。

**对本单元来说**：你不需要理解内部机制，只需要知道它把**无上下文向量**变成了**带上下文向量**。

---

## 数据流

```
向量矩阵 [5, 896]   ← 来自 u02（无上下文）
  │
  ▼
[ u03 Attention ]    ← 你现在在这里
  │  is_causal=True（不偷看未来）
  │  Q·K·V 内部投影 + 加权聚合
  ▼
向量矩阵 [5, 896]   （形状不变，内容变了）
  │  每个 token 已吸收它能看到的上下文
  ▼
[ u04 Transformer ]  → 多层堆叠，最终出 logits
```

---

## 对外接口

| 函数 | 输入 | 输出 |
|------|------|------|
| `attend(text)` | `"小猫"` | `(tokens列表, 输入向量, 输出向量)` |

对比输入/输出向量的变化，直观感受 attention 的作用。

---

## 演示输出

运行 `uv run unit_03_attention.py`，你会看到：

```
句子「小猫」tokens: ['小', '猫']
句子「黑猫」tokens: ['黑', '猫']
向量形状: [2, 896]  (输入/输出形状相同)

进入 Attention 前（u02 embedding 产出，无上下文）:
「小猫」中「猫」前4维: [ 0.0234  -0.1456   0.0089   0.0678]
「黑猫」中「猫」前4维: [ 0.0234  -0.1456   0.0089   0.0678]
→ 相同 token 向量完全一样（纯查表）

离开 Attention 后（吸收上下文）:
「小猫」中「猫」前4维: [ 0.3124  -0.4291   0.1534   0.0102]
「黑猫」中「猫」前4维: [ 0.1892  -0.6723  -0.0812   0.3445]
→ 相同 token 向量已分化
```

> **要点**：Attention 让相同 token 在上下文中产生不同的向量。形状不变 → 可堆叠多层。此处用随机权重演示机制，真实模型由训练决定。
