# 01 · Tokenization —— 文本 ⇄ token IDs

> **角色**：整条链路的入口与出口。模型只认识数字，分词器是唯一的"翻译官"。

---

## 一句话理解

把自然语言文本切成一个个 **token**（词元），每个 token 对应词表中的一个数字 ID。
模型输入必须是 ID 序列，模型输出的 ID 也必须通过分词器还原为文字。

---

## 核心概念

### Token 是什么？

Token 不是"一个字"，也不是"一个词"，而是分词器根据训练语料统计出来的**最常见片段**。

```
文本: "大语言模型（LLM）是人工智能领域的革命性技术。"
  ↓ encode()
Token: ['大', '语言', '模型', '（', 'LL', 'M', '）', '是', '人工智能', '领域', '的', '革命性', '技术', '。']
IDs:  [255064, 102417, 101909, 100353, 1992, 11494, 101260, 104350, 101026, 114039, 104208, 112411, 103467, 1773]
```

- `"大"` 是一个字 → 1 个 token
- `"语言"` 是两个字的词 → 1 个 token  
- `"LLM"` 被切成了 `"LL"` 和 `"M"` → 2 个 token（英文罕见缩写可能被拆开）
- `"革命性"` 三个字 → 1 个 token（常见词被整体编码）

### 为什么模型需要这个？

模型内部全是数学运算（矩阵乘法），**它不识字**。`"你好"` 对它没意义，`[1234, 5678]` 才有意义。
分词器就是"翻译官"——把人类文字翻译成模型能理解的数字，再把数字翻译回人类文字。

### vocab_size（词表大小）

```
Qwen3-0.6B 的 vocab_size = 151,936
```

这意味着词表里有 151,936 个 token。每个 token 有一个 0~151,935 的唯一 ID。
这个数字是模型出厂时就固定的，不能改——所有后续的矩阵维度（embedding、lm_head）
都和 vocab_size 绑定。

## 数据流

```
输入（人类文字）                   输出（模型世界）
═══════════════                  ═══════════════
"中国的首都是"   ──encode()──→  [12345, 67890, 11223, 44556, 77889]
                                  中     国     的     首     都

[12345, 67890, ...]  ──decode()──→  "中国的首都是"
```

**关键约束**：分词器和模型必须配套。用 Qwen 的分词器去解析 GPT 的模型输出会得到乱码，
因为两个"字典"完全不同。

---

## 对外接口

| 函数 | 输入 | 输出 | 说明 |
|------|------|------|------|
| `encode(text)` | `"你好"` | `[12345, 67890]` | 文本 → token ID 列表 |
| `decode(ids)` | `[12345, 67890]` | `"你好"` | token ID 列表 → 文本 |
| `decode_each(ids)` | `[12345, 67890]` | `["你", "好"]` | 逐个 token 解码，观察分词效果 |

---

## 在整条链路中的位置

```
用户输入 "中国的首都是"
  │
  ▼
[ u01 Tokenization ]   ← 你现在在这里
  │  encode() → [12345, 67890, 11223, 44556, 77889]
  ▼
[ u02 Embeddings ]     → 每个 ID 变成 896 维向量
  ▼
  ... → 最终 decode() → 输出文字
```

---

## 演示输出

运行 `uv run unit_01_tokenization.py`，你会看到：

```
文本: 大语言模型（LLM）是人工智能领域的革命性技术。
  encode() → [102275, 104139, 51613, 101908, 105146, 3837, ...]  (17 tokens)
  逐个 token: ['大', '语言', '模型', '（', 'LL', 'M', '）', ...]
  decode()  → 大语言模型（LLM）是人工智能领域的革命性技术。  (还原一致: True)
```

> **要点**：encode 把文本转为数字列表，decode 反向还原。一个 token 对应一个常见字/词片段，不是按字也不是按词。
