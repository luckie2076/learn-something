# 05 · Generation —— 自回归生成（让模型"说话"）

> **角色**：把 u04 的单次打分变成循环——选词 → 拼回输入 → 再打分 → 直到结束。
> 加上采样旋钮，让使用者控制生成风格。

---

## 一句话理解

u04 一次只输出"下一个 token 的打分"。要生成一句话，需要**反复调用** u04：
每次选一个得分最高的 token，把新 token 拼到输入后面，再打分，再选……循环往复。

---

## 自回归（Autoregressive）的含义

```
初始输入: "人工智能的未来是"
  ↓ u04.forward()
logits → token "光" 得分最高 ✓ 选了 "光"
  ↓
新输入: "人工智能的未来是光"
  ↓ u04.forward()
logits → token "明" 得分最高 ✓ 选了 "明"
  ↓
新输入: "人工智能的未来是光明"
  ↓ 循环...直到遇到终止 token 或达到 max_new_tokens
```

**"自回归"**：每生成一个 token，都把它拼回输入，作为下一次预测的条件。用自己的输出当输入——所以叫"自"回归。

---

## 采样旋钮 —— 控制生成风格

### 贪心 vs 随机采样

| 设置 | 行为 | 效果 |
|------|------|------|
| `do_sample=False` | 每次都选概率最高的那个 | 结果**确定**（同输入 → 同输出），但可能重复 |
| `do_sample=True` | 按概率分布**随机**抽取 | 结果**多变**，更像人类写作 |

### temperature —— 控制随机程度

```
temperature 的作用：把 logits 除以 T，再 softmax

T = 0.3（低温）: 高分 token 概率被放大，趋于贪心
                 "1+1=2"         ← 保守、确定

T = 1.0（常温）: 原始分布
                 "1+1=2，这是小学数学第一课"  ← 合理展开

T = 1.5（高温）: 低分也获得机会，更随机
                 "1+1=2不过说起来数学很有趣"  ← 跳跃、有创意
```

### top_k / top_p —— 控制候选范围

| 旋钮 | 含义 | 示例 |
|------|------|------|
| `top_k=50` | 只在概率最高的 50 个 token 中选 | 砍掉冷门候选 |
| `top_p=0.95` | 累积概率到 95% 就截断 | 动态调整候选数 |

通常 **temperature + top_k + top_p 三者配合使用**：
```python
generate(prompt, temperature=0.8, top_k=50, top_p=0.95)
```

---

## 终止条件

生成何时停下来？

1. **模型输出终止 token（EOS）**：模型自己觉得话说完了
2. **达到 max_new_tokens**：强制截断，防止无休止生成

---

## 数据流

```
"人工智能的未来是"
  │
  ▼
u01.encode() → IDs [123, 456, 789, ...]
  │
  ▼
┌─ 循环 ──────────────────────────────────────────┐
│                                                  │
│  u04.forward(当前 IDs) → logits [N, 151936]     │
│  logits[-1] → softmax → top-k 采样 → 选 1 个   │
│  新 token 拼到 IDs 末尾                          │
│  IDs 变长 1                                      │
│                                                  │
│  重复...直到终止 token 或 max_new_tokens          │
└──────────────────────────────────────────────────┘
  │
  ▼
u01.decode(新增的 IDs) → "光明，充满无限可能..."
```

---

## 对外接口

| 函数 | 输入 | 输出 |
|------|------|------|
| `generate_ids(ids, ...)` | token IDs + 旋钮 | 新增的 token IDs |
| `generate(prompt, ...)` | 文本 + 旋钮 | (完整文本, 新增 IDs) |

`generate_ids` 是核心——u06 直接调用它。

---

## 旋钮速查

| 参数 | 类型 | 默认值 | 作用 |
|------|------|--------|------|
| `max_new_tokens` | int | 30 | 最多生成多少个新 token |
| `do_sample` | bool | True | False=贪心, True=随机采样 |
| `temperature` | float | 1.0 | 随机程度（低=保守, 高=多样） |
| `top_k` | int | 50 | 候选池大小 |
| `top_p` | float | 1.0 | 累积概率截断阈值 |

---

## 演示输出

运行 `uv run unit_05_generation.py`，你会看到：

```
prompt: 「人工智能的未来是」
  u01.encode → token IDs: [41479, 105916, 108723, 107991, 104016, ...]

采样旋钮效果:
  do_sample=False（贪心）: 人工智能的未来是人工智能的未来...
  temperature=0.3:        人工智能的未来是智能时代的核心...
  temperature=1.5:        人工智能的未来是充满想象力和创造力...
```

> **要点**：do_sample=False 结果确定但可能重复；temperature 控制随机程度（低=保守，高=多样）；top_k/top_p 控制候选范围。
