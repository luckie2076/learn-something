# 02 · Embeddings —— token IDs → 向量

> **角色**：模型的"字典"——把每个 token ID 翻译成一个稠密向量，让数学运算成为可能。

---

## 一句话理解

词表里有 151,936 个 token 候选项。Embedding 层是一张 **[151936, 896]** 的大表：
给定一个 token ID，直接**查表**取出对应的 896 维向量。

---

## 核心概念

### hidden_dim（隐藏维度）—— 向量的"宽度"

```
Qwen3-0.6B 的 hidden_dim = 896
```

每个 token 用 **896 个浮点数** 来表达它的语义。类比：用 896 个属性来描述一个词。

```
Token "猫" 的 embedding 向量（896 维）:
[0.23, -0.57, 0.01, 0.89, 0.45, -0.12, ..., 0.67]
 ←———————————————— 共 896 个数字 ————————————————→
```

### 为什么叫"隐藏维度"？

这些向量是**模型内部表示**，你从外部看不到——它们"藏"在模型里。hidden = 内部/隐藏。

### 无上下文向量

**关键**：这个阶段的向量是**纯查表结果**。无论 `"猫"` 出现在 `"小猫"` 还是 `"黑猫"` 中，
它被查出来的向量**完全相同**。上下文区分是 u03 Attention 的工作。

```
"小猫" 中的 "猫" → embedding 查表 → [0.23, -0.57, ...]  ← 一模一样
"黑猫" 中的 "猫" → embedding 查表 → [0.23, -0.57, ...]  ← 一模一样
```

---

## 形状详解

### `[n_tokens, hidden_dim]` 是什么意思？

这**不是**一个 Python 列表 `[5, 896]`，而是**形状描述符**——表示一个二维矩阵有 n_tokens 行、hidden_dim 列。

以输入 "中国的首都是"（5 个 token）为例：

```
实际结构：
         ┌─── 896 列（每个 token 的向量维度）───┐
第 0 行:  [0.23, -0.57,  0.01,  0.89,  ...,   0.12]  ← "中" 的向量
第 1 行:  [0.45,  0.33, -0.22,  0.01,  ...,  -0.67]  ← "国" 的向量
第 2 行:  [-0.11, 0.78,  0.55, -0.93,  ...,   0.34]  ← "的" 的向量
第 3 行:  [0.02, -0.44,  0.81,  0.16,  ...,  -0.05]  ← "首" 的向量
第 4 行:  [0.91,  0.07, -0.31, -0.58,  ...,   0.77]  ← "都" 的向量
         ↑                                               ↑
     5 行 = seq_len                         每行 896 列 = hidden_dim

shape = [5, 896]      元素总数 = 5 × 896 = 4480 个浮点数
```

### 命名约定

| 写法 | 语境 | 含义 |
|------|------|------|
| `a = [5, 896]` | Python **代码** | 一个包含 2 个元素的列表 |
| `形状: [n_tokens, hidden_dim]` | **注释/描述** | n_tokens 行 × hidden_dim 列的矩阵 |
| `list(tensor.shape)` | 代码打印结果 | `[5, 896]`（描述矩阵维度的列表） |

## Embedding 查表的数学本质

```python
# 伪代码：token IDs → 向量
ids = [12345, 67890, 11223, 44556, 77889]
embedding_table = 模型内部的 [151936, 896] 矩阵

for each id in ids:
    vector = embedding_table[id]   # 取第 id 行
    # 得到 1 个 896 维的向量
```

这不是计算，是**查表**。类似 Excel 里用 VLOOKUP 按行号取整行数据。

---

## 句子级向量：text_embedding

把所有 token 向量**取平均**，得到一个代表整句话的向量：

```
"猫是一种可爱的宠物"
  ↓ token embeddings → 每个 token 一个 896 维向量
  ↓ 取平均
  → 1 个 896 维向量（句子向量）
```

然后就可以计算两句话的**余弦相似度**（越接近 1 语义越近）：

```
"猫是一种可爱的宠物" ⇔ "狗是人类忠诚的朋友" → 0.85（相近）
"猫是一种可爱的宠物" ⇔ "今天天气真不错"     → 0.12（无关）
```

## 对外接口

| 函数 | 输入 | 输出 |
|------|------|------|
| `token_embeddings(text)` | `"你好"` | `(IDs, 向量矩阵 [n_tokens, 896])` |
| `text_embedding(text)` | `"你好"` | `句子向量 [896]` |
| `similarity(a, b)` | 两个向量 | `余弦相似度 (-1~1)` |

---

## 在整条链路中的位置

```
token IDs [5]   ← u01 产出
  │
  ▼
[ u02 Embeddings ]   ← 你现在在这里
  │  查表：每个 ID → 896 维向量
  ▼
向量矩阵 [5, 896]   （无上下文）
  │
  ▼
[ u03 Attention ]    → 让向量吸收上下文
```
