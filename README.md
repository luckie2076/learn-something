# Learn

前端技术渐进式学习仓库，按技术方向分目录组织，每个目录是一个独立的学习项目。

## 项目列表

| 项目 | 主题 | 内容 |
|------|------|------|
| [frontend-basics](./frontend-basics/) | HTML / CSS / JavaScript | Web 前端三件套基础，含 HTML 语义化、CSS 布局与动画、JS 语法与 DOM 操作 |
| [jsx-basics](./jsx-basics/) | JSX 语法入门 | React 的前置知识，聚焦 JSX 标签、表达式、嵌套、条件与循环四条主线 |
| [ts](./ts/) | TypeScript | TypeScript 语法与类型系统学习示例 |
| [frontend-engineering](./frontend-engineering/) | 前端工程化 | 8 阶段路线：包管理→代码质量→样式工程→构建工具→测试→Monorepo→CI/CD→进阶架构 |
| [vite](./vite/) | Vite 插件开发 | 5 个渐进单元：插件生态→虚拟模块→transform 钩子→开发服务器→Markdown 插件实战 |
| [tailwindcss](./tailwindcss/) | Tailwind CSS v4 | 10 单元：Utility-First→布局→响应式→变体→主题→暗色模式→组件化→动画 |
| [react](./react/) | React 19 | 与官方教程对应的 4 大章节：描述 UI→添加交互→管理状态→脱围机制 |
| [vue](./vue/) | Vue 3 | 6 阶段渐进路线：框架思想→响应式→组件→组合式 API→生态→进阶 |
| [react-router](./react-router/) | React Router v8 | 8 单元：路由基础→导航→动态参数→嵌套布局→查询参数→编程式导航→路由保护→错误处理 |
| [zustand](./zustand/) | Zustand 5 | 7 单元：创建 Store→选择器→状态更新→异步操作→Slice 模式→中间件→进阶技巧 |
| [shadcnui](./shadcnui/) | shadcn/ui | 15 单元，分三大模块：环境搭建→核心组件→主题与设计系统 |
| [component-library](./component-library/) | 组件库（从零手写 CSS） | 11 单元：Button→Input→Badge→Card→Tabs→Accordion→Dropdown→Dialog→Sheet→Sidebar→SplitPane |

各项目的详细运行说明见各自目录下的 README。
