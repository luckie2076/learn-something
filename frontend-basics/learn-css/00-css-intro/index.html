CSS 引入方式与基本语法

CSS 有 3 种方式"贴"到 HTML 上，各自的适用场景不同。

一句话记住规则：选择器 { 属性: 值; }。
你写的每一条 CSS，都是在回答两个问题——「选谁」和「改成什么样」。

三种引入方式对比

方式写法适用场景推荐度
内联样式 <p style="color:red"> 临时调试、邮件 HTML ⚠️ 慎用
内部样式表 <style> 写在 <head> 里 单页演示 / 学习练习 ✅ 练习用
外部样式表 <link rel="stylesheet" href="styles.css"> 正式项目（多页共享） ⭐ 首选

为什么外部样式表最好？

  • 复用：一个 .css 文件统一样式所有页面
  • 缓存：CSS 文件被浏览器缓存，后续页面加载更快
  • 单一真相源：改一处全站生效，符合「关注点分离」—— HTML 管"是什么"，CSS 管"长什么样"

后续章节为了「单文件可独立打开」，仍会沿用内部 <style>。但请记住：真实项目用 <link> 外部样式表。

📖 练习清单

  1. 内联样式 — 写在标签 style 属性中
  2. 内部样式表 — <style> 写在 <head> 里
  3. 外部样式表 — <link> 引入独立 .css 文件
