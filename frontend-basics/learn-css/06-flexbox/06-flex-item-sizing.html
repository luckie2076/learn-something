flex-grow / flex-shrink / flex-basis — 弹性伸缩

三个属性共同控制子项的弹性行为，常用 flex 缩写。

flex: <grow> <shrink> <basis> ｜ 默认值 flex: 0 1 auto

flex-grow — 放大比例

当容器有剩余空间时，子项按比例分配。默认为 0（不放大）。

0
1
2
0

flex-shrink — 缩小比例

当容器空间不足时，子项按比例收缩。默认为 1。设为 0 则不收缩。

shrink:1
shrink:0
shrink:2

容器宽度 480px，三个子项各 140px 基础宽度 → 超出 420px + 间距。shrink:0 的项不收缩，其他按比例收缩。

flex-basis — 基础尺寸

定义子项在分配剩余空间前的初始尺寸。优先级高于 width。

basis: 200px
flex:1 (auto)
basis:300, no grow

常用 flex 缩写速查

缩写等价含义
