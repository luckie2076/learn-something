order — 子项排序

order 控制子项的排列顺序，所有子项默认为 0。数值越小越靠前（主轴方向）。

注意：order 只改变视觉顺序，不改变 DOM 结构。对无障碍和键盘导航有影响，谨慎使用。

默认顺序（DOM 顺序）

A (0)
B (0)
C (0)
D (0)

调整顺序：C 排第一，B 排最后

A (2)
B (3)
C (0)
D (1)

视觉顺序：C → D → A → B，DOM 顺序不变

实际场景：内容优先的响应式布局

桌面端侧边栏在左，移动端侧边栏在内容下方（通过媒体查询 + order 实现）

📌 侧边栏（DOM 在后，但 order 让它在桌面端排前面）
📄 主内容（DOM 在前，利于 SEO）

桌面端：order: 2 侧边栏 + order: 1 内容 → 侧边栏在左
移动端媒体查询覆盖：order: 1 侧边栏 + order: 2 内容 → 内容在上
