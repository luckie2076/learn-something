Flexbox 常见布局模式

以下是最常用的 Flex 布局模式，覆盖日常开发 90% 的场景。

1. 水平垂直居中

只需在容器加两行属性：display: flex; justify-content: center; align-items: center

始终居中

2. 导航栏

Logo 居左，菜单项居右，space-between 实现

Logo
首页关于联系

也可以把右侧菜单包在一个 div 里，用 margin-left: auto 推过去

3. 三栏：左-中-右（居中标题）

标题居中，左右两侧各放操作按钮

页面标题

4. 圣杯布局：侧边栏 + 主内容

侧边栏固定宽度，主内容自适应

侧边栏
180px
主内容区 flex:1
自动占满剩余空间

5. 卡片网格（flex-wrap 响应式）

不需媒体查询也能自动换行，配合 flex 实现等宽

卡片
卡片
卡片
卡片

flex: 1 1 200px：不换行时均分空间，小于 200px 时自动换行

6. 粘性页脚（Sticky Footer）

内容不满一屏时，页脚始终在底部

Header
内容区 flex:1 撑开剩余高度
Footer 始终在底部

7. 媒体对象（Media Object）

图片 + 文字横排，Flexbox 的经典用例

标题文字
这是一段描述文字，Flexbox 让图片和文字完美对齐。图片固定尺寸，文字自动换行。align-items: flex-start 确保文字从顶部开始。

8. 表单行（Label + Input）

label 固定宽度，input 自适应，用 align-items: baseline 对齐文字
