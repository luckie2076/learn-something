# Web 前端三件套

从零开始学习 HTML、CSS、JavaScript 的基础知识。每个子目录是独立的学习项目。

## 目录结构

| 目录 | 说明 |
|------|------|
| [html/](./html/README.md) | HTML 入门：结构、文本、链接、列表、表格、表单、语义化与多媒体 |
| [css/](./css/README.md) | CSS 渐进式学习：语法、盒模型、选择器、布局（Flex/Grid/定位）、层叠、响应式与动画 |
| [js/](./js/README.md) | JS 渐进式学习：值类型、变量、函数、作用域/闭包、数组/对象、DOM、事件、异步、模块 |

## 运行方式

直接用浏览器打开 HTML 文件即可（双击或拖入浏览器窗口）。涉及跨文件请求（外部 `.css`、`.js` 等资源）时，推荐使用本地服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

> 用本地服务器而非 `file://` 打开，能避免跨文件请求时的浏览器限制。
