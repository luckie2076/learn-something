# learn-frontend-basics

Web 前端学习练习仓库，按技术方向分目录维护子项目。

## 目录结构

| 目录         | 说明                                  |
| ------------ | ------------------------------------- |
| [`learn-html/`](learn-html/README.md)| HTML 入门练习：结构、文本、链接、列表、表格、表单、语义化与多媒体 |
| [`learn-css/`](learn-css/README.md) | CSS 渐进式学习：语法、盒模型、选择器、布局(Flex/Grid/定位)、层叠、响应式与动画 |
| [`learn-js/`](learn-js/README.md) | JS 渐进式学习：值类型、变量、函数、作用域/闭包、数组/对象、DOM、事件、异步、模块 |

## 约定

- 各子项目相互独立，进入对应目录查看其 `README.md` 了解主题导览。

## 怎么运行

1. 直接用浏览器打开文件（双击，或拖入浏览器窗口）；
2. 或在本目录起一个本地服务器（涉及跨文件请求、外部 `.css` 等资源时推荐）：

  ```bash
  python3 -m http.server 8000
  ```

  然后访问 `http://localhost:8000`。

> 用本地服务器而非 `file://` 打开，能避免跨文件请求（如外部样式表、相对资源）时的浏览器限制。
