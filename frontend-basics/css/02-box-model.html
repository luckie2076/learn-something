盒模型：每个元素都是盒子

1) 四层结构

content（绿底是 padding，含在背景里）

元素实际占据的宽度 = content(200) + padding(左右各20) + border(左右各10) = 260px。 外圈的 margin(30) 是与其他元素的透明间距，不计入自身宽高。

2) 为什么推荐 box-sizing: border-box

content-box（width 不含 padding/border，实际 260px 宽）
border-box（width 含 padding/border，实际 200px 宽）

两个盒子都写了 width:200px，但占宽不同—— 这正是日常布局"明明设了宽度却对不齐"的根因。解决：给全局加 * { box-sizing: border-box; }。

3) margin 塌陷

上盒子 margin:30
下盒子 margin:30

两盒垂直间距不是 60，而是 30（取较大值）。这是 CSS 的垂直 margin 塌陷规则。
