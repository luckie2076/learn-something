选择器：给元素贴地址

① 基础选择器

我是 #header（ID 选择器：深底白字）

我是 .card（类选择器：粉色粗边框 + 底色盒子）

普通 <p>（元素选择器：深灰字）

② 后代 vs 子选择器（关键区别）

  • 直接子项（子+后代都命中 → 加粗 + 蓝底）
  • 直接子项
    • 嵌套项（仅后代命中 → 蓝字但「不加粗、无蓝底」）

对比上面：嵌套的 <li> 是蓝色（被后代选择器命中），却没有加粗、没有蓝底（没被子选择器命中）——这就是「空格(后代)」与「>(子)」的差别。

③ 相邻 vs 通用兄弟

小标题 h2

紧跟 h2 的第一个 p（相邻兄弟 +：黄底高亮）

第二个 p（通用兄弟 ~：红字斜体，无黄底）

第三个 p（同样通用兄弟 ~：红字斜体）

可见：相邻兄弟 + 只命中「紧挨 h2 的第一个 p」（黄底）；通用兄弟 ~ 命中「h2 之后所有同级 p」（红字斜体）。第一个 p 同时满足两者，所以黄底+红斜体。

三类选择器覆盖了 90% 场景：元素 / 类 / 组合。ID 只在「整页唯一锚点」时用。
