justify-content — 主轴对齐

控制子项在主轴方向上的分布方式。默认主轴为水平方向。

space-between / space-around / space-evenly 对比

space-between：首尾贴边，中间均分。
space-around：每个子项左右间距相等 → 首尾间距是中间的一半。
space-evenly：所有间隙（含首尾）完全相等。
