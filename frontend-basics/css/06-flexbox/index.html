Flexbox：一维布局

Flex 是 CSS 一维布局方案，一行 display: flex 即可解决对齐、分布、自适应问题。

核心概念：Flex 容器有两条轴——主轴（main axis）和交叉轴（cross axis）。
容器属性控制整体排列，子项属性控制个体行为。

📦 容器属性

  1. flex-direction — 主轴方向（row / column / 反向）
  2. justify-content — 主轴对齐方式（居中、两端、均匀分布）
  3. align-items — 交叉轴对齐方式
  4. flex-wrap — 是否换行 + align-content 多行对齐
  5. gap — 子项间距（替代 margin hack）

🧩 子项属性

  1. flex-grow / flex-shrink / flex-basis — 弹性伸缩与基础尺寸
  2. align-self — 单个子项覆盖交叉轴对齐
  3. order — 子项排序

🏗️ 实战布局

  1. 常见布局模式 — 居中 / 导航栏 / 侧边栏 / 卡片网格 / 粘性页脚
学习建议：按序浏览，每个示例都可以直接修改代码观察效果。掌握 Flex 后再学 Grid（二维布局）。
