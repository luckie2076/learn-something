gap — 子项间距

gap 是设置子项之间间距的现代方式，替代了旧式的 margin hack。

注意：gap 只作用于子项之间，不会在容器边缘产生额外间距。这与 margin 不同。

gap vs margin 对比

gap：间距仅在子项之间，容器边缘无多余间隙。代码简洁。
margin：每个子项都要设 margin，且首尾子项会在容器边缘产生间距，需要额外处理（如 :first-child / :last-child 或负 margin）。
