# learn-html

HTML 入门练习。每个文件聚焦一个主题，代码刻意保持极简，**重点在注释里讲清「为什么这样做」**，而不是罗列标签用法。

> 学习顺序建议按文件编号从 0 到 7 依次看，它们是一个由骨架到细节的递进关系。

## 文件导览

| 文件 | 主题 | 核心「为什么」 |
| ---- | ---- | ------------ |
| [`00-structure.html`](00-structure.html) | 文档结构 | 为什么 `<!DOCTYPE html>` 要放第一行？它决定了浏览器用「标准模式」而非「怪异模式」解析，直接关乎盒模型与默认样式的正确性。 |
| [`01-text.html`](01-text.html) | 文本与排版 | 为什么用 `<h1>`~`<h6>` 而非大字号 `<div>`？标题自带语义层级，机器（SEO、读屏软件）才能理解结构。 |
| [`02-links-images.html`](02-links-images.html) | 链接与图片 | 为什么 `<img>` 必须有 `alt`？它是图片加载失败或读屏时的兜底文本，是可访问性的必需项。 |
| [`03-lists.html`](03-lists.html) | 列表 | 为什么区分 `ul` / `ol` / `dl`？它们分别表达「无序、有序、术语-解释」三种不同语义，而非仅仅外观。 |
| [`04-tables.html`](04-tables.html) | 表格 | 为什么表格只用于「表格数据」？现代布局应交给 CSS Grid/Flex，用表格排版会失去语义与灵活性。 |
| [`05-forms.html`](05-forms.html) | 表单 | 为什么 `<label for>` 要关联 `<input id>`？点击文字即可聚焦，且对读屏用户友好。 |
| [`06-semantic.html`](06-semantic.html) | 语义化结构 | 为什么用 `<header>/<main>/<article>` 而非一堆 `<div>`？结构自带含义，利于 SEO、可维护性与无障碍。 |
| [`07-media.html`](07-media.html) | 多媒体 | 为什么 `<audio>/<video>` 要加 `controls`？否则控件不显示、用户无法播放；`picture` 则用于按条件选图的响应式兼容。 |
| [`08-url.html`](08-url.html) | URL 定位方式 | 为什么相对 URL 要分「文档相对 / 父级相对 / 根相对」？浏览器靠「基准地址」拼接，而 `<base>` 能改写这个基准——这是链接 404 与图片裂图的根因。（配套目标页：[`08-page2.html`](08-page2.html)） |

## 一条贯穿始终的主线

这一组练习反复在传递同一个观念：**HTML 写的不是「长什么样」，而是「是什么意思」**。标签的语义（semantic）比外观更重要——外观交给 CSS，含义留在 HTML。这也是为什么每个文件都强调 `alt`、`lang`、语义化标签这些「看不见但很重要」的东西。
