URL 定位方式

浏览器拿到一个 href 后，会用「基准地址」和它拼接成真正能访问的地址。基准地址默认是“当前页面地址”，可被 <base> 改写。

1. 绝对 URL

MDN（绝对地址）

2. 文档相对 URL

同目录文件（文档相对）

3. 父级相对 URL

上级目录的样式（父级相对）

4. 根相对 URL

站点根下的资源（根相对）

5. 锚点 / 片段

跳到本页顶部 跳到另一页的 #sec 段落

6. 查询参数

带参数的搜索链接

7. 特殊 scheme

发邮件 打电话

观察建议

用本地服务器（python3 -m http.server）打开本页，再把鼠标悬停在链接上看浏览器状态栏解析出的完整地址；然后注释掉 <base> 刷新，对比相对地址如何变化。
