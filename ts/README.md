# learn-ts

TypeScript 语法与类型系统学习示例。

## 怎么运行

见仓库根目录 [README.md](../README.md) 的「怎么运行 → TypeScript 项目」：先 `npm install`，再 `npx tsc main.ts && node main.js`（或 `ts-node` 直接运行）。

## 文件说明

| 文件            | 说明                       |
| --------------- | -------------------------- |
| `main.ts`       | TypeScript 语法示例源码     |
| `main.js`       | 编译后的 JS 产物            |
| `package.json`  | 项目配置与依赖              |
